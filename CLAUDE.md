# CLAUDE.md — FRC Team 8352 CODE Gold robot code

Off-season (2026-27) robot code for 313 Robotics / FRC Team 8352 CODE Gold.
Repo: https://github.com/CodeGold8352/SDS-Kraken-Base-Drive (public fork of carrierussell/SDS-Kraken-Base-Drive).

## Stack
- WPILib 2026 (GradleRIO 2026.2.1), Java, command-based
- CTRE Phoenix 6 (26.3.0) swerve, generated by Phoenix Tuner X: SDS modules, Kraken X60 drive + steer, CANcoders, Pigeon 2 (ID 5)
- PathPlannerLib 2026.1.2 for autos

## Layout
- `generated/TunerConstants.java` — Tuner X output. Don't hand-edit module offsets/IDs; regenerate from Tuner X instead.
- `subsystems/CommandSwerveDrivetrain.java` — drivetrain + `configureAutoBuilder()` (PathPlanner, ApplyRobotSpeeds with wheel force feedforwards; path PID translation 10, rotation 7; flips paths on red)
- `RobotContainer.java` — Xbox driver bindings, "Auto Mode" SendableChooser built by `AutoBuilder.buildAutoChooser("Square Test")`
- `src/main/deploy/pathplanner/` — PathPlanner GUI files. `settings.json` = robot config (30 lb, 26x25 in bumpers, MOI estimated 0.95 kg·m²). Edit paths/autos in the PathPlanner app, not by hand.

## Autos
- `Square Test` (folder Tuning): 4 straight 2 m legs (2,3)->(4,3)->(4,5)->(2,5)->(2,3), heading held 0°, 1.5 m/s, stops at each corner. Used to tune path PID and check odometry drift: measure end-position error over 5 runs.

## Git workflow
- `main` is protected: PR + 1 approval, stale approvals dismissed, conversations must be resolved.
- Auto work branches off `autos` — one branch per routine, e.g. `autos-2-piece-center`. (Use a dash, not a slash: git can't have both `autos` and `autos/...` branches.)

## Conventions for Claude
- Students learn from this code: explain changes, keep comments clear, prefer small focused diffs.
- Build with `./gradlew build`; test autos in simulation (Simulate Robot Code) before the real robot.
- Don't change PID gains, current limits, or robot config values without saying why and what was measured.
